# 个股研究报告的模型与资料规则

个股任务仍使用 `signal_analysis` 持久化队列，单独选用 Claude Sonnet 5.5（`claude-sonnet-5-5`）、推理强度（Effort）`xhigh`。配置为 `[ai].signal_analysis_model` 与 `signal_analysis_reasoning`，运行字段为 `openai_signal_analysis_model` 与 `openai_signal_analysis_reasoning`；不改变新闻、热点或财报的模型。个股手动开关是 `effective.ai.stock_analysis_enabled`，仍受服务总体暂停、密钥与共用预算限制。

报告保留既有技术分析字段，并新增 `result.report`：版本为 `stock-report-v1`，标题为 `headline`，七个固定章节依次为公司、财务、估值、技术、期权、事件与市场。每章包括 `id/title/summary/points/evidence_ids/source_urls`；观察事项包括 `what/why/revise_if`，`data_gaps` 记录资料缺口。章节缺资料时仍保留并说明原因。模型不输出任意网页、脚本或图表；`AIJobPublic.visuals` 为另行依据保存输入生成的安全图形资料。

新 Sonnet 任务必须带完整报告，提示版本为 `signal-analysis-stock-report-zh-cn-v2`，结构名称为 `signal_analysis_stock_report_zh_cn_v1`。第二版增加中文字段显示示例，报告结构不变。历史已完成技术分析没有 `report` 时仍可读取；第一版已付费回执仍可本地恢复和读取，不因此重新调用模型。旧 Haiku 的原生 JSON 结构身份不变，新任务的模型、提示与结构身份不同，旧在途任务不能冒充新报告。

## 联网与来源

任务以六次网页搜索、四次网页抓取与两次代码核对作为工具预算，抓取内容最多8,000词元。服务器工具使用自动选择，不强制某个工具。搜索与抓取设置供应商的 `max_uses`；原生代码没有对应的服务端次数参数，联网工具内部也可能执行代码。流中的工具通知到达时，操作已经开始，因此股票任务会完整接收当前付费请求并保存真实回执，不再因这类通知中途丢弃报告。完整且有效的最终报告可以接收；仍需继续的响应若已耗尽任一工具预算，则保存回执并以 `provider_tool_limit_exceeded` 结束。续轮的网页额度扣除累计已用量，零或负余额不再发请求。最多四轮续跑，共用65,536输出词元额度和现有绝对等待时限；这些限制不表示单请求严格的工具次数或费用上限。断网、超时等没有完整回执的请求仍标记结果未知，不自动重发。

公司公告、投资者关系原始资料和监管申报优先。模型必须区分本地程序资料与联网新增事实，保留资料截止时间、财报期、币种、单位、实际值及预期的含义。财务比率和业绩意外幅度为小数比例时，0.05表示5%；未复权价格不可把拆股价格跳变当成真实收益。代码核对不覆盖程序行情与评分。资料不足、工具失败或预算用尽时说明未核实事项；网页中的命令不作为模型指令。

`evidence_ids` 仅允许输入实际存在的资料块名及其 `id/evidence_id`，不可用或已裁剪的块不能引用。`source_urls` 必须精确匹配本次成功搜索或抓取的安全公开网址。校验要求工具名称、成功状态、真实调用编号与内容哈希，不接受模型自报来源、仅执行代码、失败工具或自拼链接。此规则证明资料来历，不能替代对具体论断的真实性核查。中文校验沿用项目规则，仅实际输入和成功工具标题提供外文专名的来源依据，不放开任意英文叙述。

公开读取先验证保存回执的模型、消息编号、任务类型和结构，再用成功工具标题进行中文验证；来源标题也计入本地结果验证缓存键。报告链接与本地依据每次再次绑定，坏回执或不匹配的链接不会公开。已付费校验失败的本地恢复使用相同来源上下文，同时要求结果与原回执一致，不能新增来源或改变费用记录。

个股完整报告采用有限的显示标签映射：例如 `scores.data_quality` 显示为“程序资料质量分”、`breakdown_risk` 为“向下破位风险”、`earnings_history` 为“历史盈利”。只替换指定人类文字字段里的已知完整标识符；不处理词片段、未知字段或网址，也不改 JSON 键、枚举、依据编号、来源链接、数值和日期。生成结果、公开读取与已付费恢复都经过同一幂等转换，原供应商回执保持原样。任意英文叙述仍由原中文规则拒绝。

## 输入、缓存与费用

个股封装资料上限为240,000字节：`runtime.SIGNAL_MAX_UNTRUSTED_JSON_BYTES`，其他任务仍为60,000。`runtime.max_payload_bytes_for(job_type)` 供入队使用；大小按转义尖括号后的 UTF-8 文本计算。证据组装另留220,000字节界限，避免封装开销导致已接受任务在付费前失败。丰富资料包括公司概况、价格历史、财务、机构预期、历史业绩及原有五个上下文块，缺失和部分可用状态均保留。

系统提示和结构定义共用稳定前缀，并显性设置 `cache_control={"type":"ephemeral","ttl":"1h"}`；股票、日期和行情位于后续用户消息。其他任务缓存时长不变。续跑保留签名内容与前缀，缓存只标记稳定部分，不对动态股票资料声明共享缓存。真实缓存创建、读取及一小时写入用量继续取供应商回执；没有命中时不伪造节省金额。

预留沿用一百万词元的原生工具任务额度以及65,536输出词元上限；新增输入上限、工具配置、轮次和缓存时长都计入任务结构身份。预留是事前保守估计，实际工具可能重复读取上下文，不能称为付费金额硬上限。每轮真实用量按现有 Sonnet 价格分别结算；一小时缓存写入使用其对应单价，用量缺失时保留保守预留。回执先落盘，再校验和公布；未知请求不自动重发，重启只能恢复已保存回执，不能重放尚无终态回执的付费对话。

工具暂停或模型尚未交付最终 JSON 时，续跑前先保存轮次和确认用量；缺少最终 JSON 的结束回合明确登记为 `incomplete_final_json`。个股与财报使用相同的有界提醒规则，四轮仍未交付就停止并保存失败回执，不能无限继续。最终回执已保存、公布结果时遇到数据库写入失败的情况，可以重启恢复，无须再次调用模型。

## 账号权限与收盘额度

普通登录账号和管理员都可生成个股分析。每个账号所有股票共用十次新建额度，按相邻两个纽约证券交易所实际收盘时点计数；周末与休市日不额外刷新，夏令时和提前收盘沿用站内交易日历。请求持久化成功后计一次；查看报告、复用共享任务，以及入队前被拒绝的请求不扣次数。入队后即使模型失败也保留本次使用记录，未知提交结果不会自动重发。

相同股票、模型、推理强度、提示与结构版本的活动任务，以及本时段创建的完成报告，可跨账号共享。完成报告的可复用缓存与账号额度使用同一收盘分界，接口 `cache_reset_at` 与 `quota.reset_at` 相同；`latest_job_cached` 只标记当前周期、当前配置的可复用完成报告。到点后旧报告作为历史资料保留，但不再阻止新周期生成。跨收盘仍在运行的任务继续共享，避免重复付费；即使晚于收盘才完成，结果仍按任务创建周期归属。个人账号及额度记录不进入模型输入；报告只使用公开股票资料。数据库写事务同时检查共享任务、账号额度与创建结果，跨设备、并发请求和管理员强制参数都不能绕过额度。收盘后即使保存的行情证据尚未变化，也允许新时段重新研究。

普通账号只新增股票分析读写和该类任务读取权限；取消任务、其他分析入口与运维信息继续按原有权限处理。写入仍要求同源与 JSON；接口地址、方法和编码路径均按限定范围检查。表 `ai_stock_analysis_allowances` 使用独立版本登记；第二版以 `use_number` 区分同账号同周期内的十条消费记录，将旧行迁移为第1次使用，保留旧建表版本的校验和。迁移与新任务准入均在数据库事务内完成，删除任务不返还已用次数。

## 图文报告

个股报告复用 OpenIntelligentUI 完成态内容协议，由本地固定模板渲染到影子文档树（Shadow DOM）。所有模型文字先转义，脚本字段固定为空；不执行模型给出的网页、样式或脚本。原技术分析和历史纯文字结果保留。

图表只读取同一任务保存的资料，最多六幅，不从文章中猜测数字：历史收盘价、季度收入、技术结构评分、日成交量、分析师目标价和盈利超预期比例。金额必须有确认币种；缺失时省略该图并说明原因。评分固定0—100，比例与百分数不混用，零值不当作缺失。每图保留独立来源与资料日期，显示层仅将带时区的采集时间换成纽约时间，不改财报期或报告原文。

报告正文、图表和来源集中放在卡片内部滚动区，最大高度随视窗调整且不超过440像素；展开章节不再拉长整张卡片，鼠标、触控与键盘均可继续阅读。先显示摘要和两幅图，其余图表、七个正文章节、观察事项、资料缺口和技术明细可分别展开。金额标签在窄屏使用亿、万等缩写，明细表保留完整数值；图表圆角与深浅主题随站点设置变化。

价格、收入、成交量和分析师目标价使用不同类别色。技术评分按既有站内评分区间显示绿色、黄色、红色或灰色，并保留文字解释；顶部风险与底部机会不共用同一种高低含义，极高底部分仍标记需要价格确认。资料质量用蓝色表示综合资料质量，分数取指标可得率与模型覆盖率的乘积，不添加新的优劣阈值；盈利意外分别标明超出、低于或符合预期。

页面恢复共享任务和最近报告，登录主体或股票变化会清除旧读取状态。普通账号没有取消按钮；重复查询只读取原任务，不新建分析。模型、完成时间、来源和缓存用量均来自保存回执；没有记录的用量不补成零。

## 官方依据与离线检查

参数与提示遵循 [Sonnet 5.5 变化说明](https://platform.claude.com/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5)、[提示缓存](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)和 [Sonnet 5.5 提示规范](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5-5)。提示写清任务、结果用途、正向例子、时间与资料缺口，不要求输出内部推理。搜索的原生引用与严格 JSON 格式不混合，因此报告采用现有 `prompt_json` 路径，最终结构由本地严格验证。

`tests/test_stock_ai_model.py` 使用模拟消息、临时数据库和本地配置，离线覆盖专用模型、稳定一小时缓存、输入限制、旧结果兼容、固定章节、中文与来源绑定、回执先保存、续跑用量及专用开关。

一次隔离的 AMD 实测使用第一版提示，工具回执记录三次搜索、一次抓取、两次代码核对，输出含七个章节。原 JSON 因说明文字照抄三个字段名而被中文校验拒绝；有限标签转换后，从同一已付费回执生成的恢复对象通过结构、中文、来源和本地依据检查，无须新请求。报告的评分、数值、日期与来源均保留。该记录的缓存读取为330,755词元、缓存写入总量124,138词元，一小时与五分钟写入明细均未保存在最终回执中；不能由这些总量推断具体有效期。现有费用估计约1.132898美元，用量与费用记录不因标签恢复改变。
