## 经核验保留的差异

- 枢轴函数在 `NaN` 窗口中的行为不同；Python 最大值与数组最大值不可机械互换。
- 聚类的两种实现都使用总体标准差。浮点极小误差会改变近乎并列聚类的排序：三次 1000 与三次 15.3 的样本能得到不同结果。保留各自实现并加入特征检查。
- 详情页、雷达与趋势模型对短历史的波幅处理分别可能缩短窗口、返回空或返回零；本轮不改变金融公式边界。
- Yahoo 会话失败后已有日志与降级回退；没有把此类行情故障扩大成整个服务启动失败。
- `firstString` 与 `pickS` 的空白值和空结果不同；只共用对象解析，不合并字符串规则。
- JSON 往返复制承担去掉 `undefined` 字段的持久化语义，未直接替换为另一种复制方法。
- 股票代码的大小写、前缀与字符范围各有输入边界；未用同一正则覆盖所有入口。
- 所有者测试准备函数继续保持模块作用范围；组件工具配置、纽约时间语义别名、历史迁移、明确隔离的研究/性能代码保留。
- 注释、横幅和旧包名不作为批量删改目标；解释时区、权限、回退及兼容原因的说明继续保留。

没有新增算法类别、调整选股门槛或启用尚未合并的研究分支。
