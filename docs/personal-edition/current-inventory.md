# 个人版现行清单

更新时间：2026-07-17。

## 常驻服务

| 服务 | 职责 | 主要写入 |
|---|---|---|
| `backend` | 网页、Owner 访问、查询和任务创建 | 用户请求与任务入队 |
| `worker` | 扫描、新闻同步、焦点、模型任务和维护 | `DATA_DIR` 下的数据库与快照 |

正式组合配置只有这两个服务和一个 `optix-data` 卷。两者使用同一镜像、只读根文件系统和非根用户。

## 十类后台工作

| 工作 | 作用 | 关闭或异常时的表现 |
|---|---|---|
| `breakout` | 定时突破候选与生命周期 | 保留旧快照，记录禁用或降级 |
| `catalyst_sync` | 从 MacroLens 拉取新闻、日历和来源状态 | 等待配置、冷却或记录来源错误 |
| `focus` | 建立焦点快照与热点上下文 | 保留上一份有效上下文 |
| `ai_jobs` | 处理 Owner 已创建的模型任务 | 无密钥、超预算或无任务时不提交 |
| `maintenance` | 备份、清理和完整性维护 | 只操作本地数据 |
| `public_home` | 定时保存匿名首页所需的六类行情数据 | 单项失败保留上一份成功结果，不运行模型 |
| `macro_conditions` | 拉取 FRED 与 ETF 代理，重算 Optix 宏观环境快照 | 定时与手动共用同一任务；无 FRED 密钥时报告 disabled 而不是失败；刷新失败保留上一份有效快照 |
| `focus_refresh` | 消费 Owner 发起的焦点池立即刷新 | 复用同类在途请求，失败保留旧快照 |
| `strength_refresh` | 消费 Owner 发起的强度雷达立即刷新 | 与其他手动工作分开报告运行状态 |
| `breakout_refresh` | 消费 Owner 发起的突破雷达立即刷新 | 不把真实扫描当成健康检查 |
| `retention` | 消费 Owner 发起的保留期维护 | 与自动`maintenance`分开记录状态 |

## 访问状态

产品只有三种可见状态：

1. `private_network`：来源地址合格，进入即为 Owner；
2. `password` 未登录：可浏览公开研究页面、研究数据和已有分析，但没有刷新、扫描、设置、维护或模型任务权限；
3. `password` 已登录：成为 Owner。

未登录访问只命中明确列出的公开路由，并只读取仍在允许时限内的缓存或已经保存的快照。快照缺失或过期时返回 503，不会访问外部行情源、启动后台刷新、修改应用数据或保存刷新结果；新闻响应也不会读取所有者预算、令牌用量和活动任务。

Owner 能看到所有日常按钮，并可在页头手动关闭或开启模型分析。关闭时新的手动与定时分析都停止；重新开启只恢复手动分析。刷新或分析被阻止时，原因来自访问状态、模式、数据上下文、工作进程、预算、并发或冷却。

## 配置清单

`.env.example` 不再含正式配置，只保留迁移兼容说明；`machine.env.example` 有七个机器字段，`secrets.env.example` 有五个服务端密钥，合计 12 项。模型、推理等级、访问模式、功能模式、任务频率、定时时刻、并发、每日任务数、每日美元预留和保留期均由 `config/personal.toml` 管理。

MacroLens 连接只有：

- `machine.env` 中的 `MACROLENS_URL`；
- `secrets.env` 中的 `INTERNAL_API_TOKEN`。

没有反向动作接口、独立动作密钥或逐工作进程开关。

## 手动能力

- 以下能力只对 Owner 开放；公开访客只读取已经保存的结果；
- 新闻、日历、来源状态、焦点池、强度雷达和突破雷达支持持久化手动刷新；
- 单篇新闻支持首次分析与重新分析，历史修订保留；
- 热点支持正常消费新修订，也支持不推进消费版本的当前上下文强制重跑；
- 重试和取消沿用任务状态机；
- 同类重复请求复用已有任务，避免重复提交和重复预留费用。

## 运行约束

- 自动逐条新闻分析保持关闭；手动与定时模式由 `catalyst_mode` 决定。
- 付费任务最大并发为一，并受每日任务数和每日美元硬上限共同限制。
- 提交前按任务最大输入、最大输出和工具上限预留最坏费用；取得供应商终态用量后保守回填，缺少用量或提交结果不明时保留整笔预留。
- 财报影响任务不启用网页搜索（Web Search），因为供应商没有公布默认搜索返回内容的数值型令牌上限。
- `/ready` 不依赖外部新闻、行情或模型服务。
- 工作进程健康检查只读本地锁、心跳和任务清单。
- 用户可见新闻标题、摘要和分析使用简体中文。
