# 个人版删除与收束记录

本文原为删除计划，现已转为完成记录。每项均以生产导入、路由、网页引用、容器条目、脚本、文档和测试为检查边界。

| 已退出范围 | 现行替代 | 验收结果 |
|---|---|---|
| 四个独立工作容器 | 单一`worker`服务 | 正式编排只有`backend`与`worker`，健康清单严格包含九类任务 |
| 双编排文件 | 正式`docker-compose.yml` | 部署、健康检查与回滚文档均使用同一入口 |
| 逐工作进程部署门禁 | 后端就绪与统一工作进程清单 | 检查过程不创建任务、不刷新新闻、不扫描行情 |
| 多方向签名、随机数和轮换密钥 | 超文本传输安全协议（HTTPS）与`INTERNAL_API_TOKEN` | MacroLens 只向 Option Pro 提供只读数据，不存在反向动作或焦点拉取 |
| 浏览器令牌、公开读取开关与动作密钥 | 私有网络或 Owner 密码会话 | 页面和接口共用同一边界，前端不再保存或发送密钥 |
| 环境文件中的行为开关 | `config/personal.toml` | 访问模式、模型、预算、频率和功能模式不再由环境变量覆盖 |
| 四个独立数据文件路径 | `DATA_DIR` | 数据库、进程锁、快照、运行设置和备份均从同一根目录派生 |
| 旧 MacroLens 名称与运行时别名 | `MACROLENS_URL`+`INTERNAL_API_TOKEN` | 新名称是唯一运行时入口，旧名称只在迁移工具与删除回归断言中出现 |
| 旧前端页面与样式 | Night Desk 现行资源 | 生产页面、完整性检查和测试均无旧资源引用 |

旧数据库表不随运行代码一起删除。旧 Catalyst 数据、分析修订和任务记录至少保留 90 天，只供读取、审计和导出。任何数据清理都必须由后续独立变更完成，并附带备份、抽查和恢复演练证据。

详细替代路径、引用证据和回滚信息见`deleted-components.md`。
