# Option Pro 深度审查与界面优化

日期：2026-09-05。审查起点：`2d2bc2ac1bb509c3c318df2c11210117fe6c2ecd`。修改位于本地分支 `codex/security-logic-ui-review`，尚未提交、推送或部署。

本次发现并修复了登录保护、请求资源消耗、期权权限、相对强弱计算、报价时间和自动刷新等问题；同时调整共享界面组件，将布局、键盘操作、数值展示和动效规则集中管理。结论来自代码检查和本地测试，不能解释为线上环境已经修复，也不能证明所有可能的问题都不存在。

## 主要修复

| 问题 | 原先的影响 | 修改后的行为 |
| --- | --- | --- |
| 登录自己的账号会清空来源地址的失败记录 | 可以反复重置猜测其他账号密码的冷却计数 | 成功登录不清空地址级失败记录，记录按时间窗口过期 |
| 请求正文没有统一入口上限 | 字段校验前仍可能完整读取、解析很大的无效请求 | 登录、注册上限 4 KiB，其他接口上限 2 MiB，分块接收也检查实际大小 |
| 反复登录持续增加会话记录 | 一个普通账号可长期累积会话、占用存储 | 每账号最多保留 20 个有效会话；事务保证并发签发不能突破上限 |
| 新注册允许一字符密码 | 极短密码容易猜中，散列运算不能弥补密码本身过弱 | 新注册至少 15 个字符，拒绝有限本地常见口令；保留历史账号登录兼容 |
| 默认访客期权查询仍可触发外部请求 | 关闭访客拉取后，换标的仍能消耗供应商请求 | 默认访客只读有效缓存；所有者或显式开放开关后才允许冷查询 |
| 两种期权缓存的有效期交错 | 到期日列表先过期时，仍有效的期权链被误报不可用 | 先读取有效期权链缓存，不为缓存读取增加外部请求 |
| 相对强弱的两条收益曲线日期错位 | 个股与基准缺少不同日线时，可能产生虚假的跑赢或跑输 | 按个股窗口的相同起止交易日比较；缺少端点时返回缺失值 |
| 清理后的有效价格不足 | 空序列可能报错，短序列仍可能进入评分 | 按有效收盘价数量检查最低样本要求 |
| 预期波动使用无关合约的报价时间 | 新报价可能替旧合约证明“新鲜”，展示时间也可能偏新 | 逐合约检查时间，展示实际选中两侧报价中较早的时间 |
| 手动刷新后自动刷新不再更新页面 | 后续请求成功返回，结果却被旧请求版本检查丢弃 | 定时刷新和恢复可见时使用当前版本，旧请求仍不能覆盖新结果 |
| 自定义图表提示直接拼接数据文本 | 数据字段可能被当作网页标签解释 | 统一转义文本并限制颜色格式；没有将此缺口夸大为已证明的远程攻击 |
| 本地开发默认代理生产站点 | 调试时可能误向线上接口写入 | 默认连接本机后端，其他环境需明确配置 |

登录绕过的优先级为 P1，其余资源与权限问题及适用条件见[安全审查](SECURITY_REVIEW_2026-09-05.md)。具体数据样本、修复前后结果和时间口径见[业务逻辑审查](LOGIC_REVIEW_2026-09-05.md)。

新注册的密码长度参考[美国国家标准与技术研究院（NIST）的现行单因素密码指南](https://pages.nist.gov/800-63-4/sp800-63b.html)。本项目没有因此宣称符合该指南的全部要求；本地常见口令表也不等于完整泄露密码库。

## 界面与动效

保留项目现有的浅色市场研究工作台，优先完善共享组件和信息表达。没有引入新的在线字体或远程视觉资源。

| 参考来源 | 在项目中的使用 |
| --- | --- |
| [Beautiful UI](https://www.beautifului.dev/) | 延续洞察卡片的信息层次，把读数、变化和比较基准放在一起；改善次要文字对比度 |
| [beUI](https://beui.dev/) | 统一标签滑块、按钮反馈和已有弹性参数；减少动态效果时取消位移 |
| [Rare UI](https://www.rareui.com/) | 首次显示真实数值，读屏始终读取最终值；修复动画中途改值、后台恢复和系统偏好变化 |
| [Transitions.dev](https://transitions.dev/skill.html) | 按菜单、抽屉、提示、骨架的用途复用时长；修复快速开关、计时清理与透明浮层残留 |
| [shadcn/ui](https://ui.shadcn.com/docs/components/radix/select) | 选择菜单使用其组合方式与 Radix 基础组件，提供键盘选择、焦点恢复、边缘避让和浮层挂载 |

具体变化包括：

- 菜单不再被父容器裁切，方向键、首尾跳转、确认和退出行为一致；数值和空字符串选项保留原有值类型。
- 表格恢复原生行与单元格语义，详情和选择使用真正的链接或按钮；行内操作不会误触整行。缺失评分在正反排序中均排末尾。
- 增加“跳到主要内容”的键盘入口；切换新页面后恢复顶部和内容焦点；个股页补齐主标题。
- 价格立即显示真实值；评分的装饰动画与读屏文本分离。减少动态效果的系统设置在页面打开后更改也会生效。
- 连续通知最多保留四条，鼠标停留或键盘阅读期间暂停自动关闭；定时器随通知卸载清理。
- 修复刷新时重复触发涨跌闪动、图表配置更新与缩放窗口的冲突，以及宏观数据日期未变时刷新状态迟迟不结束。
- 演示构建常驻标注示例数据；正式构建仍使用真实接口，并检查未混入演示行情。

完整参数、组件入口、使用约束和验收要求见[界面与动效规范](UI_DESIGN_SYSTEM.md)。五个来源的核验版本、适配方式与许可保存在 `THIRD_PARTY_NOTICES.md` 和 `third_party/`，容器也会包含许可文件。

## 范围与剩余限制

- 本机没有容器工具（Docker），相关后端测试跳过；容器启动、编排、生产数据库、真实供应商权限和额度没有在本次本地环境验证。
- 原有浏览器套件中依赖完整行情后端的页面取证存在跳过项；隔离样例的通过不能替代所有线上数据组合。
- 没有核验当前生产提交、防火墙、源站绕过、边缘代理或多实例限流。进程内限流不等于整个部署共享限流。
- 公开研究页面与自主注册仍是产品现有访问方式；这不构成仅朋友可访问的边界。旧账号的历史短密码没有被强制改写。
- 构建仍提示部分压缩文件大于 500 kB，入口约 907 kB、图表约 642 kB；加载资源的后续细分仍有优化空间。本次没有将构建通过等同于性能已经最优。
- 未发布、未运行生产扫描、未进行付费模型调用或生产压力测试。正式部署后仍需验证真实会话、缓存预热和供应商返回数据。
