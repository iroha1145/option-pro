# 前端审计修复与保留项

本轮以 `1123ef56670a3004899bb575fedd499d0d129268` 为基线，处理 2026 年 9 月 22 日前端审计复核确认的问题。原报告主表共有 18 项，其中 6 项存在所述代码现象、7 项部分成立、5 项不成立或应保留。成立不代表原报告给出的严重级别成立。

## 处理范围

雷达接口的归一化结果应如实表达缺失的价格、评分、区间和服务状态。组件应读取同一份类型定义，编译器不能再把可能为空的数据当成必有数值。

测试应验证扫描、排序、重试及布局行为。原有依赖注释、空格和手工模拟状态写入的用例改用实际组件或稳定的函数入口。迁移不以减少测试数量为目标，也不以单元测试总数衡量覆盖是否保留。

完全相同的强度色阶共用已有函数。风险反色、空值、动画与不同显示方式保留各自的语义。

独立检查类型链路时还确认了两处原有的价格问题，作为独立功能修复处理：现价缺失时不能用触发价回填；个股历史事件列表标为“触发价”的字段必须取事件价，不能取现价。两种价格分别保留空值，回归用例覆盖单边缺失和数值不同的情景。

## 18 项处置

| 原序号 | 处置 |
|---:|---|
| 1 | 去除以注释位置截取选股组件的测试；保留催化批次失败、重试、过期、慢批次和取消后的迟到响应覆盖。 |
| 2 | 去除扫描组件中按 `setXxx` 名称推断状态写入的测试环境，转为真实页面操作及独立函数测试。 |
| 3 | 图表测试不再用精确源码拼写和空格判断覆盖层是否正确；验证数据、图表行为和必要的结构约束。 |
| 4 | 财报布局依靠已有的多尺寸浏览器测试验证，保留渲染文字与缺失值断言，去除固定样式类字符串要求。 |
| 5 | 选股页已有独立过滤器、表格、扫描流程等模块。只围绕本次验证所需职责调整，不因行数重写状态系统。 |
| 6 | 图表已分离指标、投影与绘图控制器。本次未证明性能故障，保留现有编排；改进其回归验证。 |
| 7 | 绘图控制器已分离持久化、命中、吸附、拖拽实现；无明确行为收益的进一步拆分暂不进行。 |
| 8 | 共用公共强度色阶函数；追高风险反色及评分条呈现规则保留。 |
| 9 | 期权到期日与财报日期分别保留过期值、无效值、缓存和午夜切换规则，不能直接互换。 |
| 10 | 私有日期格式器并非全部等价。纯交易日、分钟时刻、输入校验及回退各有含义，本轮不机械合并。 |
| 11 | 保留 `cacheStatusProps` 的字段筛选用途，不把资源对象的额外字段一并传入组件。 |
| 12 | 统一真实可空的雷达输出类型，移除掩盖空值的类型转换，核验调用方与归一化结果。 |
| 13 | 分析进度接口具有独立契约与调用方，保留模块边界。 |
| 14 | 保留用于表达纽约时钟用途的别名。 |
| 15 | 预取失败可以被忽略，正式读取仍走错误与重试路径；本轮不改变此策略。 |
| 16 | 周历计时器本来就有卸载清理，保留其刷新闪烁行为。 |
| 17 | 首页日期轮询与公共日期 Hook 的更新时机不同；未证明卡顿，不为微小复用改变刷新频率。 |
| 18 | 保留解释时区、权限、缺失数据与竞态原因的注释，不按历史审计编号批量删除。 |

本轮没有改变后端算法、日期口径、预取异常策略或绘图状态所有权。价格显示的上述修正与保持行为的类型、结构整理分别提交。合并和部署的最终版本、检查结果及服务证据另见发布记录。
