发现了哪个失败模式？实际改了哪条规则？收益、尾部、覆盖、时效和成本如何变化？哪些值得保留，哪些应该放弃？

## 1. 决策摘要

最有证据的失败模式是：**生产综合 ranking 的全池 IC 尚可，但 Top5/Top10 弱于 mid/long 趋势本身。** 复杂项（short、RSI、突破、市场拟合、画像）没有把头部选得更好；63 日动量能抓头，但尾部和账本回撤明显更差。雷达侧的失败模式是：**日线第一触发本身几乎没有同池超额**，假突破多；强确认能挑出更好的子集，但会丢掉大量机会。

实际改动（全部默认关闭，可切换回滚）：

- 排序：A0 = `0.5 * score_mid + 0.5 * score_long`（家族分，不是页面 94/6 混合键）
- 风险：C0 = 原排序 Top10、同一主行业最多 2，空位保留
- 时点：T1 日线强确认；T2 再等一根收盘
- 后续：F1 相对强弱过滤；F2 收益因子分位数后 A0

**线上默认排序不改。** A0 在开发区过关，验证区点估计仍为正（+26bps）但 CI 含 0，且最差 5% 从 -14.0% 恶化到 -15.5%，超过预登记 50bps 尾部容差。A0 只保留为研究开关。C0 不当 alpha（开发区配对不够门槛）。F1/F2 放弃。T2 放弃作默认确认。T1 只保留为可选“强标签”，不替换默认触发。

验证区 354 日（2023-01-03 至 2024-05-30）已在冻结后跑完。封存区未揭盲。验证数字见 `~/research/screener-radar-data/runs/algorithm-round-validation/validation-metrics-slim.json`。C0 在验证区配对 +50bps 且 CI 不含 0，这是冻结后看到的基线事实，不据此回头把 C0 升为采用候选。

## 4. 归因

- A0 的头部改善来自**去掉 short/RSI/突破/市场项，只留 mid/long 趋势**，不是换池、不是换期限、不是改退出。
- C0 的变化来自**集中度约束**，不是排序公式。
- T1 的条件超额来自**量能+K 线位置过滤**，代价是覆盖。
- T2 几乎只是**延迟一天**，不是新的结构判断。
- 账本 A0 净值更高，但不能单独证明可交易优势：空仓补位、拒单和路径依赖很大。
- 共同市场暴露：2020 放大所有趋势规则；2021 A0/动量/F2 都更差。没有单独的择时实验（后续预算已用完）。
