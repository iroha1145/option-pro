## 测试证据修正

原选股浏览器夹具自行实现任务接口并使用进程内字典；它绕过了实际队列和任务终态的嵌套结构。多个用例还共用此前已刷新的快照，允许零次计算通过并发断言。

本轮改为生产任务路由、独立队列数据库、真实 `WorkerSupervisor`、真实扫描器和真实快照读取。后台执行器与测试接口运行在同一隔离进程，未声称验证正式双容器部署。每条用例停止旧执行器，重新创建数据目录与数据库；强制覆盖继承的 `DATA_DIR`，避免读取开发者的应用数据。

浏览器现在访问生产构建的预览服务。连续点击要求恰好一次提交与计算；双标签要求恰好一次计算；桌面与移动流程同时核对任务参数、发布状态、页面评分日期和旧价消失。供应商失败用例核对任务失败、旧行与扫描时间不变、快照文件摘要不变。成功轨迹和诊断摘要加入持续集成附件。

原生浏览器缓存测试现在打包并执行实际 `marketGet`，关闭应用内缓存后先证明 HTTP 缓存命中，再证明强制读取到达服务端；没有注册会关闭浏览器缓存的路由拦截。
